The Problem

Information asymmetry is the real tax on doing business in complex jurisdictions. Contracts are drafted from inherited templates nobody re-reads. Regulatory circulars arrive weekly and are interpreted by the loudest voice in the room, not the most accurate reading of the text.

The consequence is structural disadvantage. A small exporter negotiating terms has no way to audit clauses against prevailing case law. A founder signing papers has no way to flag that terms are 3× market standard. A cooperative has no way to verify agreement compliance with regulatory caps.

StitchMark Space is built for this exact environment. It ingests the statute, reads the clause, cites the source, and — critically — argues with itself in public before letting the answer reach the user.

Implementation

Core Techniques

01
Vertex AI RAG + Reranking

Two-stage retrieval: RAG ingests PDFs into vector stores (1024 tokens / 200 overlap for statutes). Semantic reranker scores top-20 down to 5 — single biggest quality lever.

02
Gemini Synthesis + Judge

Gemini Pro (T=0.1) synthesises from ranked chunks. Flash (T=0.0) acts as adversarial evaluator, returning faithfulness score, citations check, and severity assessment.

03
SHA-256 Provenance Chain

Every interaction SHA-256 chained to previous hash. Genesis hash chains to first, first to second, etc. Any tampering breaks entire session audit trail.

04
Modal Serverless Ledger

Persistence via append-only NDJSON volumes and session dicts on Modal. Zero idle cost. Cryptographic reproducibility. Single GCS backup = complete restore point.

05
Firebase JWT + RBAC

Every endpoint gated by require_role() dependency. Three roles: admin (ingest, batch eval), analyst (risk, redline, query), viewer (query, eval read).

06
Cloud Scheduler Batch

Cloud Scheduler fires POST /eval/batch every 6 hours. Re-evaluates every REVIEW verdict. Turns static test harness into continuous evaluation loop.

Knowledge

Lessons Learned

Things the documentation doesn't tell you. Eight production blockers. Eight precise interventions.

01
Serverless beats managed, always

RAG Engine's default managed-Spanner hit capacity limits. Switching to serverless via REST PATCH unlocked pipeline. When Google ships two paths, newer one is usually less congested.

02
Reranking is not optional

Raw embeddings retrieve plausible chunks. Semantic reranker retrieves right chunks. Faithfulness delta between reranked/unreranked is roughly +0.15. Difference between PASS and REVIEW verdicts.

03
Adversarial judge must be runtime feature

Test-suite judge runs in CI and is forgotten. Inline judge visible to user — severity icons, expandable challenge — transforms from "AI answer machine" to "evidentiary instrument".

04
Provenance chaining is priceless

Ten lines of SHA-256 code enable tamper-evident audit trails. Legal/compliance teams can verify answer authenticity across sessions. Cheap to implement, invaluable in regulated domains.

05
Citations are architecture, not decoration

Decorative citations are worse than no citations. Every cite must be verified against source at runtime. User interface should highlight which claims lack grounding. Citations → product edge.

06
Regulatory domains need audit-first design

Not enough for system to be accurate. System must be verifiable by humans. Dashboard showing faithfulness scores, verdicts, challenges, logs is not nice-to-have — it is load-bearing product.
